Computer Skills Review and Readiness

Bring the beginner skills together in realistic tasks. This lesson checks whether you can independently perform the basic actions needed for the next level. You need 80% or higher on the mastery test to unlock the next lesson.

1. The complete beginner workflow

A confident beginner can start a computer, sign in safely, use the mouse and keyboard, open programs, manage windows, create folders, save files, copy and move files, use basic settings and shut down correctly.

2. Task 1 — Create an organized workspace

Step 1: open File Explorer. Step 2: create a folder named `Emmy J Practice`. Step 3: inside it create `Documents` and `Images`. Step 4: open a text editor. Step 5: type a short paragraph. Step 6: save it inside Documents with a meaningful name. Step 7: close the editor. Step 8: open the saved file again.

3. Task 2 — Manage a file

Step 1: find your saved file. Step 2: rename it. Step 3: copy it to another folder. Step 4: confirm that both copies exist. Step 5: delete the copied version. Step 6: open Recycle Bin and restore it. Step 7: verify that it returned to its previous location.

4. Task 3 — Use programs and windows

Open two programs. Minimize one. Switch to the other. Use Alt + Tab to switch between them. Resize one window. Close both after finishing. If either program asks whether to save, make the correct choice based on whether you changed anything.

5. Task 4 — Safe computer use

Lock the computer with Windows key + L. Unlock it. Identify where Wi-Fi settings can be found. Identify the sound output control. Check that the vents are not blocked. Explain what you would do if the computer became unusually hot, produced smoke or showed a suspicious security warning.

6. Final self-check

You are ready to move forward when you can perform the tasks without needing someone to click for you. If you forget a step, return to the relevant lesson, practise it again, and then retry. Mastery is about understanding and doing, not memorizing words.

Quick practice

Now perform the practical task in this lesson on a real computer whenever possible. If you cannot perform it yet, repeat the steps slowly until you can do them without guessing.
