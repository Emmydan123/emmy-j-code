Hardware and Software

Understand the difference between physical equipment and programs, then learn how software is opened, closed, installed and handled safely. You need 80% or higher on the mastery test to unlock the next lesson.

1. Hardware

Hardware is the physical equipment you can touch: keyboard, display, mouse, CPU, RAM, storage drive, motherboard, speakers, printer and other components. Hardware cannot decide what task to perform by itself; it works with software and instructions.

2. Software

Software is the set of programs and instructions that tell the computer what to do. Examples include an operating system, web browser, word processor, media player and security software.

3. Operating system versus application

The operating system manages core computer resources and provides the environment in which applications run. Windows, macOS and Linux distributions are examples of operating systems. A word processor or browser is an application that performs a particular kind of task.

4. How to open a program

On Windows, one common method is: 1) click Start, 2) type the program name, 3) look at the search result, 4) click the correct application, 5) wait for its window to open. Another method is to use a desktop or taskbar shortcut when one exists.

5. How to close a program

When finished, save your work first. Then click the Close button on the program window. If the program asks whether you want to save changes, choose Save if you need the work, or Discard/Don’t Save only when you are certain you do not need those changes.

6. Installing software safely

Only install software from a trustworthy source. Read the program name carefully. Avoid clicking advertisements pretending to be download buttons. During installation, read each screen instead of repeatedly clicking Next. Decline optional software you do not recognize.

7. Updating software

Updates can fix bugs, improve security and add features. When a trusted operating system or application offers an update, read what it is for and allow the update when appropriate. Keep your device connected to power during major updates if possible.

8. Practice task

Open a program, identify its title bar and main working area, create a small piece of content, save it if appropriate, close the program, and reopen it. Explain which parts were hardware and which were software.
