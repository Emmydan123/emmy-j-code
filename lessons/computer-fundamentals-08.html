The Desktop and Windows

Learn how to recognize the Windows desktop, open and manage windows, use the Start menu and taskbar, and move around the screen confidently. You need 80% or higher on the mastery test to unlock the next lesson.

1. What the desktop is

The desktop is the main workspace you see after signing in. It may contain icons, a background, the taskbar and other interface elements. The desktop is not the same thing as your entire computer; it is one part of the operating system interface.

2. The taskbar

The taskbar provides quick access to the Start menu, search and running or pinned applications. The exact appearance varies by Windows version and settings.

Try this: move the pointer over an application icon. Click once to open or switch to it. If a program is already open, its taskbar icon can bring its window forward.

3. Start menu and search

Step 1: click Start. Step 2: type the name of an app or setting. Step 3: read the results. Step 4: click the result you actually want. Search is often faster than manually browsing through many menus.

4. Understanding a window

A typical application window has a title area and controls such as minimize, maximize/restore and close. The main area contains the program’s content.

Minimize hides the window from the desktop while keeping it open. Maximize expands it to fill the screen. Restore returns it to a smaller size. Close ends the window or closes the application depending on the program.

5. Moving and resizing windows

To move a window, place the pointer on an appropriate empty area of the title bar, hold the left mouse button, move the mouse, and release. To resize a resizable window, move to an edge or corner until the pointer changes, then drag.

6. Switching between programs

Alt + Tab lets you switch between open windows. Hold Alt and tap Tab until the desired window is selected, then release. Use this carefully while learning so you understand which window is active.

7. Practice task

Open two programs. Resize one, move it, minimize it, restore it, and switch between both using Alt + Tab. Then close both programs.

Quick practice

Now perform the practical task in this lesson on a real computer whenever possible. If you cannot perform it yet, repeat the steps slowly until you can do them without guessing.
