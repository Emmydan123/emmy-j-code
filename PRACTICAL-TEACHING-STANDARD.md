# Emmy J Code — Practical Teaching Standard

Every course topic must teach the learner how to perform the skill, not merely name or define it.

Each topic should include:
- What it is and why it matters
- Where the tool/control is found
- Step-by-step procedures
- What the learner should expect to see
- Real examples
- Guided practice
- Independent practical tasks
- Common mistakes and troubleshooting
- Real-world assignments
- Assessment that tests both knowledge and ability to perform the task

This standard applies to Beginner, Intermediate, Advanced, and Programming. Major applications such as email, Word, Excel, PowerPoint, browsers, Windows, networking, security, and troubleshooting are taught as practical skills with procedures and projects.
