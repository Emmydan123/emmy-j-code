# Emmy J Code Media Workflow

For each practical lesson, media should demonstrate the same procedure taught in text.

1. Screen-record the task from a clean desktop.
2. Keep cursor movement visible and zoom important controls.
3. Narrate every meaningful action: where you click, what you select, and what should happen.
4. Produce captions in WebVTT and a plain transcript.
5. Export a high-quality master, then create a web delivery copy when needed for slow connections.
6. Put video in `media/video`, audio in `media/audio`, images in `media/images`, captions in `media/captions`, scripts in `media/scripts`.
7. Register the asset in `media/media-manifest.json` using the lesson id.
8. Never make media required to understand the lesson: the full written procedure remains available.

Offline mode intentionally keeps text/progress available while media stays online.
