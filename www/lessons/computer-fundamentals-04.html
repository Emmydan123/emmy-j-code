Input, Processing, Output and Storage

Learn the four ideas that explain what happens during everyday computer tasks and use them to understand real examples. You need 80% or higher on the mastery test to unlock the next lesson.

1. Input

Input is information or commands sent into the computer. Typing, clicking, touching a compatible screen, scanning a document, recording sound and using a webcam are examples.

When you type a sentence, the keyboard sends information. When you click a button, the mouse sends an instruction about where and what you selected.

2. Processing

Processing is the work the computer performs on the input. The CPU executes instructions, while other hardware helps move and hold data. Software determines the task the computer should perform.

3. Output

Output is the result presented to you. A screen displays text and images, speakers produce sound, headphones deliver audio, and a printer produces a physical copy.

4. Storage

Storage keeps data for later. Common storage includes an SSD, hard drive and USB flash drive. Storage is different from RAM because stored data is intended to remain available after the computer is turned off.

5. Follow a complete example

Suppose you want to save a document. Step 1: type the document using the keyboard — input. Step 2: the computer processes the keystrokes and document commands. Step 3: the document appears on the screen — output. Step 4: choose Save and select a storage location — storage.

6. Use the model to troubleshoot

If you cannot hear a video, ask which stage is failing. Is the input okay? Is the computer processing the video? Is the output device selected and working? Is the file available in storage? This way of thinking helps you troubleshoot logically instead of guessing.

7. Practice task

Choose three real activities: typing a document, printing a file and playing a song. For each one, identify the input, processing, output and storage involved.

Quick practice

Now perform the practical task in this lesson on a real computer whenever possible. If you cannot perform it yet, repeat the steps slowly until you can do them without guessing.
