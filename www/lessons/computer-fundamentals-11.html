Programs, Apps and Basic Settings

Learn how to find programs, use common application controls, change safe basic settings and recognize settings you should not change carelessly. You need 80% or higher on the mastery test to unlock the next lesson.

1. Finding an app

Use Start/search rather than clicking unknown files. Step 1: click Start. Step 2: type the app name. Step 3: check the result name and icon. Step 4: open it.

2. Using menus and buttons

Many applications contain menus, buttons, tabs and dialog boxes. Read labels before clicking. If a button is disabled, the application may require another action first. If a dialog asks for confirmation, read the question rather than clicking automatically.

3. Basic display settings

You may safely explore settings such as display brightness, scaling and background. On Windows, open Settings from Start, choose the relevant category, make one change, observe the result, and keep the change only if it improves usability.

4. Sound settings

To change volume, use the speaker control in the taskbar or Settings. Check the selected output device if you cannot hear sound. If headphones are connected, audio may be routed there instead of the built-in speakers.

5. Network settings

You can view available Wi-Fi networks and connect to a network for which you have permission and the correct password. Open the network control, choose the intended network, select Connect, enter the password, and wait for the connection status. Never join unknown networks just because they are available.

6. Safe experimentation

When learning settings, change one thing at a time. Write down what you changed. Avoid advanced system settings, security settings or device-driver changes unless the lesson specifically teaches them. If a setting causes a problem, return to the previous value when possible.

7. Practice task

Open Settings. Locate display settings and identify where brightness or scaling can be changed. Locate sound settings and identify the output device. Locate network settings and identify the current connection. Do not change anything you do not understand.

Quick practice

Now perform the practical task in this lesson on a real computer whenever possible. If you cannot perform it yet, repeat the steps slowly until you can do them without guessing.
