What Is a Computer?

Learn what a computer is, what it does, how information moves through it, and how to begin using one safely. You need 80% or higher on the mastery test to unlock the next lesson.

1. What you are learning

A computer is an electronic device that accepts data, follows instructions, processes information, produces results, and can store information for later use. A computer is useful because it can perform many different tasks when the right instructions and input are provided.

You do not need to know advanced technology before you can use a computer. In this course you will learn the practical actions first, then the technical ideas that explain why those actions work.

2. Data, information and instructions

Data is raw input such as a name, number, photograph, sound recording or typed sentence. Information is data that has been organized or processed so it is useful. Instructions tell the computer what operations to perform.

For example, when you type your name into a form, the letters are data. The website may process the data and show a confirmation message. The software instructions control what happens.

3. The basic computer cycle

Most computer tasks can be understood as input → processing → output, with storage used when information must be kept. Input might be typing or clicking. Processing is the work performed by the computer. Output is what you receive, such as text on a screen or sound from speakers. Storage keeps files and other information for later.

4. How to start using a computer

Before pressing buttons, sit comfortably and check that the computer is connected to power if needed. For a desktop, check that the monitor and computer are connected. For a laptop, open the lid carefully.

  1. Step 1: Locate the power button. It may have the universal power symbol.
  2. Step 2: Press it once. Do not repeatedly press it.
  3. Step 3: Wait while the computer starts. You may see a logo, loading indicator, or sign-in screen.
  4. Step 4: If a password or PIN is requested, enter your own credentials. Never enter another person’s password without permission.
  5. Step 5: Wait for the desktop to finish loading before opening several programs.

5. A first real task

Try a simple observation task. Start the computer, sign in, look at the desktop, identify the taskbar, open one application, and close it again. The goal is not speed; the goal is knowing what you are doing.

If you are using a real computer, follow this sequence: 1) start the computer, 2) sign in, 3) look at the desktop, 4) open one app from the Start menu, 5) observe the window, 6) close the app using its Close button.

6. Common beginner mistakes

Do not press the power button repeatedly because a slow start is not necessarily a problem. Do not unplug a computer while it is running unless there is an emergency. Do not install random programs simply because a pop-up asks you to. If something unexpected appears, stop and read the message.

7. Practice task

Without looking back, explain in your own words what input, processing, output and storage mean. Then, on a real computer, start one application and close it. Write down what you clicked and what you saw.

Quick practice

Now perform the practical task in this lesson on a real computer whenever possible. If you cannot perform it yet, repeat the steps slowly until you can do them without guessing.
