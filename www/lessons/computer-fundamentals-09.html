Files, Folders and Storage Locations

Learn how to create, name, open, copy, move, rename, delete and recover files and folders using File Explorer. You need 80% or higher on the mastery test to unlock the next lesson.

1. File and folder basics

A file contains information such as a document, photo or audio recording. A folder is a container used to organize files and sometimes other folders. A storage location is where those items are kept, such as the computer’s internal drive or a USB drive.

2. Open File Explorer

On Windows, one common method is to press Windows key + E. File Explorer lets you browse storage locations and manage files and folders.

3. Create a folder

Step 1: open File Explorer. Step 2: choose the location where you want the folder. Step 3: right-click an empty area. Step 4: choose New → Folder. Step 5: type a clear name such as `My Documents`. Step 6: press Enter.

4. Create and save a file

Open a suitable application, create content, choose File → Save or use Ctrl + S, choose the correct folder, enter a meaningful file name, check the file type if necessary, and click Save. Remember where you saved it.

5. Rename

Select the file or folder. Right-click it and choose Rename, or use an available rename command. Type the new name and press Enter. Do not remove a file extension unless you know why you are doing so.

6. Copy versus move

Copy creates another version in a different location while keeping the original. Move changes where the original is located.

To copy: select the item, press Ctrl + C, open the destination, press Ctrl + V. To move: select the item, press Ctrl + X, open the destination, press Ctrl + V.

7. Delete and recover

When you delete many ordinary Windows files, they may go to the Recycle Bin first. If you deleted something by mistake, open Recycle Bin, find the item, right-click it and choose Restore. Emptying the Recycle Bin removes those items from that recovery location.

8. Search for a file

If you know the name or part of the name, use File Explorer’s search field. Type a distinctive word and wait for results. Check the location and file type before opening a result.

9. Practice task

Create a folder named `My Computer Practice`. Inside it create two folders: `Documents` and `Pictures`. Create or copy a text file into Documents, rename it, copy it to another folder, then delete the copy and restore it from the Recycle Bin.
